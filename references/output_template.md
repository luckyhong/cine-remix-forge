# 完整文档输出模板

最终交付固定用这个顺序拼装：

```markdown
# 《片名》深度解说词 + 原创动画短片《动画片名》

**叙述人设**：[用的哪个人设，见 narration_style_library.md]
**外部查重**：已搜索确认——[关键信息] / 未搜索，基于训练知识，置信度[高/中/低]——[为什么]
**关键细节查重**：[反转依赖的最关键细节] 本身已经是常见解读的一部分（深度来自：[怎么组合/延伸的]） / 本身不算常见解读
**三层反驳**：候选反驳A——[…]；候选反驳B——[…]；选用 [A/B]，因为 [为什么这个更难接住]；回应见【[具体幕]】

（以上四行是 Step 2 的必填声明，见 AGENTS.md；不是装饰性的元信息，是给下一次生成和人工复核用的可核查记录）

## 一、深度解说词

（按 script_format_guide.md 的分幕格式写完整正文）

## 二、原创动画短片剧本《动画片名》

（按 animation_fable_guide.md 的剧本格式写完整正文，标注"完全原创，人物/情节/设定与原电影无关，仅主题呼应"）

## 三、创作手法对照表

| 手法 | 解说词中的处理 | 动画剧本中的处理 |
|---|---|---|
| 开篇钩子 | … | … |
| 核心论点/主题 | … | … |
| 转折/对照设计 | … | … |
| 首尾呼应 | … | … |
```

对照表不是可有可无的附加项——它是这份文档除了两份成稿之外的第三个价值点，让用户能拆出方法论自己复用，而不只是拿到两篇成品。

**表格的四行标签是起点，不是模板**：上面四行是最常见、几乎每次都适用的分类，但不是唯一可能出现的行，也不保证每一行的具体名字都适合这部电影。组装文档前，把每一行的标签换成这部电影的解说词和动画剧本实际做了什么再重新看一遍——比如"转折/对照设计"这一行，如果这部电影的解说词结构本质是历史时代的重复循环（像《我这一辈子》），"循环结构"是准确的标签；但如果这部电影的解说词结构是两条人物线持续并行对照、没有真正意义上的"重复一轮又一轮"（比如《肖申克的救赎》里布鲁克斯和安迪的双线对照），继续套用"循环结构"这个标签就是从上一个案例的表格照抄行名，而不是描述这次实际发生的事——这种情况应该把行名改成准确的名字，例如"平行对照"，哪怕这意味着这次的表格行名和过去某次案例不一样。**允许、且鼓励**改写行名或替换/增加一行，只要新行名准确对应这部电影的处理——判断标准很具体：填完某一行后，读一遍这一行"解说词中的处理"那一格，问自己"这句描述里的关键词（比如'循环'）是不是能在解说词正文里找到对应的具体证据"，不能就换一个词。
