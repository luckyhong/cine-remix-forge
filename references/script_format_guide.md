# 解说词格式规范与钩子设计方法论

> 下面的钩子句式、转折句、收尾模式，都是**严肃反转型**（当前默认人设）下的具体写法。如果本次生成
> 选择了其他叙述人设，具体措辞变体见 [`references/narration_style_library.md`](narration_style_library.md)——
> 方法论（幕结构、时长、判断句的功能）仍然通用，只是"怎么说"会变。

## 一、固定格式标记

每一幕用三级标记，缺一不可：

```markdown
### 【MM:SS - MM:SS】幕标题

**【画面】** 具体的场景描述——谁在做什么、镜头看到了什么，写得像分镜提示，不是剧情梗概。

**【音效】**（可选，用在情绪转折点）简短的声音设计提示。

**【文案】** 这一幕实际要念出来的解说词正文。
```

时长控制：一部8-16分钟的解说词，通常拆成 5-7 幕。开篇钩子幕和结尾升华幕各占全片的10-15%，中间的历史/剧情推进幕平分剩下的篇幅，越往后幕与幕之间的节奏可以适当加快（用更短的幕、更快的转折），制造"崩坏加速"的阅读体验。

## 二、开篇钩子的几种可复用句式

不要罗列剧情简介开场，用下面这类结构之一起手（这是模式，不是可以直接套用的成句，每次要按当前电影的具体主题重新组织语言）：

- **二选一悖论式**："如果一个人穷尽一生都在做'正确的事'，最后却依然……，这到底是A，还是B？"——用一个非黑即白的追问，逼观众先站队，再在解说过程中拆掉这个二选一。
- **反常识翻案式**：先说出大众对这部作品/这个人物最常见的评价，然后直接说"但今天我想反过来讲"，制造预期违背。
- **场景切片倒叙式**：直接截取电影里情绪张力最强的一个片段（不需要台词，用画面描述就够），几秒之后再切回"大家好，今天聊……"的常规开场，用悬念代替介绍。
- **数据/事实反差式**：用一个具体的、可核实的历史事实或数字开场，制造"这跟我以为的不一样"的认知落差。

## 三、幕与幕之间的"转折句"

每一幕结束前，用一句**加粗的判断句**收束这一幕想让观众记住的核心信息，而不是用"接下来发生了……"这种流水账式的过渡。这句话应该是一个**可以独立摘出来发朋友圈**的判断，而不是剧情总结。判断句的常见结构：

- "这就是……最深层的病理：……"
- "这个细节戳破的，不是……，而是……"
- "……不是巧合能解释的分量。"

## 四、跨作品对照怎么用

选一部**观众大概率也看过或听过**的作品做对照，不要选太冷门的例子（对照的意义在于借用观众已有的认知，而不是再科普一部新作品）。对照的重点不是"两部作品讲了同一件事"，而是**找一个具体的差异点**，用这个差异点反过来让当前作品的独特之处更锐利——单纯说"这部电影和XX很像"没有价值，说"这部电影和XX表面相似，但关键区别在于……"才有价值。

## 五、结尾升华与收尾

结尾幕做两件事：

1. **升华**：把电影里的具体故事收束成一个更普世的论点，最好能让观众联系到自己当下的生活处境，而不是停留在"这是一段历史"的安全距离外。可以在这里补充一处真实的历史/传记信息作为"现实比电影更重"的收尾重锤——前提是这个信息你有把握是真实的。
2. **收尾句**：一句简短的、留有余味的总结，加上一句自然的关注/下期预告类的口播收尾（频道名用占位符，交给用户自己填）。

## 六、一处常见误区

不要把"深度"等同于"信息量大"。堆砌越多历史细节、人名、年份，解说词读起来越像维基百科词条。真正的深度来自**论点的层次感**——先给一个观众直觉上认可的解读，再推翻它，再给出更深一层的解读，这种"打脸式"的推进节奏，比单线条堆事实更让人有"学到了"的感觉。

## 七、画面时长与文案密度匹配规则

一幕的时长由时间戳决定，但文案朗读时长（按 250-300 字/分钟折算）经常明显短于——有时也会长于——这个时长。空出来的画面时间不能靠一句"镜头缓缓扫过"糊弄过去：【画面】这个字段真正的读者，是拿着这份文档去剪实拍素材的人，他需要知道具体切几个镜头、每个镜头停多久、空出来的时间该放什么，而不是一段可以套在任何电影上的抽象描述。

### 7.1 自检公式：画面覆盖不满整幕

```
spoken_seconds  = 文案字数 × 0.2 ~ 0.24（对应 250-300 字/分钟的语速区间）
gap_seconds     = 幕时长秒数 − spoken_seconds（取较慢语速估算，即较宽容的 gap）
gap_ratio       = gap_seconds / 幕时长秒数
```

满足以下两个条件时，**强制**把【画面】拆成带时间戳的分镜清单：

- `gap_seconds ≥ 20 秒`（低于这个绝对值，再高的比例也不值得拆——比如一个15秒的过渡幕，拆成三行时间戳纯属过度工程）
- `gap_ratio` 达到对应门槛：**开篇钩子幕 / 结尾升华幕 ≥ 25%**，**其余幕（含高潮幕）≥ 35%**

开篇和结尾门槛更低，是因为这两幕本来就短、以画面和情绪定调为主（见一、五）；中间的历史/剧情推进幕允许更大的天然疏密差——一段流畅描述覆盖一个多拍情节点是正当的写法，不是偷懒，所以门槛更宽松。

触发拆分后，最少分镜数按空档大小算，不是拍脑袋定一个固定数字：

```
gap_shots       = ceil(gap_seconds / 25)   # 每25秒空白至少一个独立分镜
min_total_shots = max(3, 文案自然分拍数 + gap_shots)
```

25秒的依据：单个镜头（无论是否定格）持续超过约10秒都不发生任何变化，读起来会像失误而不是导演选择（对应下面"定格延时"封顶2-4秒的原因）；25秒的桶正好能容纳2-3个这样的镜头，是一个有实际意义的检查颗粒度，不是"每5秒切一刀"式的机械拆分。

### 7.2 反向检查：文案超量

现在的格式也没检查过一幕的文案是不是塞得太满、念不完这段时长——这是一个对称的、同样真实的问题：

```
spoken_seconds_fastest = 文案字数 × 0.2（按300字/分钟，对文案最宽容的估算）
overflow_ratio = (spoken_seconds_fastest − 幕时长秒数) / 幕时长秒数
```

`overflow_ratio > 10%` 时必须处理：**删减这一幕的文案字数，或调整这一幕及相邻幕的时间戳**。这里的容忍度（10%）比疏密检查更紧，因为这不是创作判断，是对"8-16分钟总时长/250-300字每分钟"这条硬性要求的直接违反——按最快的合理语速估算依然念不完，说明文案客观超量，不存在"这是有意为之"的解释空间。

### 7.3 分镜清单格式

触发 7.1 后，【画面】从一段描述改成多条时间戳分镜，加总必须精确覆盖这一幕的完整时长；文案覆盖的部分如果本身没有自然的多拍分句，可以保留为一条。示例（对应一个90秒的开篇钩子幕，文案约80字）：

```markdown
**【画面】**
00:00-00:04　定格延时：手指停在开关上的瞬间定格，光影忽明忽暗
00:04-00:12　沉默反应镜：镜头缓慢推近至眼睛特写，无新增文案
00:12-00:45　（文案在此念出，画面为缓慢环绕镜头）
00:45-01:12　空镜转场：窗外街景流转，纯氛围段，无台词
01:12-01:30　资料闪切：闪切一张相关年代的历史资料照片，2秒后渐隐
```

### 7.4 分镜手法库：填满空档时别再写"镜头缓缓扫过"

下面8种手法各自机制不同，触发拆分的幕**至少要出现2种不同手法**——只用同一种手法机械重复填满清单，跟写一句"镜头缓缓扫过"本质上是同一种偷懒，只是看起来更花哨。

| 手法 | 机制 | 用在什么拍点 | 时长上限 |
|---|---|---|---|
| **空镜转场** | 切到一个和主体无直接关联的环境细节，靠它承载时间流逝或情绪沉淀 | 判断句落地后／跨年份叙述中 | 4-8秒 |
| **声画错位剪辑**（J-cut/L-cut） | 声音先于或滞后于画面完成切换，制造声画错位的转场感 | 情绪不同的两拍之间 | 重叠1-3秒 |
| **沉默反应镜** | 停留在一个纯反应上（表情、一个小动作），不新增文案 | 重判断句落地之后 | 2-4秒 |
| **定格延时** | 动作进行到一半时冻结，作为一个呼吸点 | 转折句/揭示瞬间 | 2-4秒（硬上限，更长会读成失误） |
| **平行蒙太奇** | 2-3个镜头快速交替，替代一段静态场景描述 | 文案出现"多年后"/"与此同时"这类跨时空陈述 | 单镜2-3秒，总长8-15秒 |
| **慢镜头强调** | 改变画面的时间流速，需在描述里写明大致倍速 | 全片情绪最高点，全片限用1-2次，多用就稀释成装饰 | 3-6秒（对应实际动作1-2秒） |
| **环境音独白段** | 画面完全不变，全靠【音效】承载这段时间 | 需要沉浸感/等待感的拍点 | 10-20秒 |
| **资料闪切/文字卡插入** | 插入一张真实的历史照片/文字卡，给电影画面本身给不了的史实背书 | 数据/事实反差式钩子、收尾处的史料重锤 | 2-4秒 |

举两个具体例子，说明这些手法不是抽象概念：

- 念到"这一年，全厂三分之一的人被辞退"之后，画面切到车间墙上那台还在运转的老钟——秒针走了三圈，无人看管（**空镜转场**）。
- 念到"接下来的五年，两人各自过着完全不同的生活"时，快速交替剪三组镜头：她在异乡加班到深夜／他在老家务农的背影／两人手机屏幕上从未点开的未读消息（**平行蒙太奇**）。

### 7.5 豁免情形：不是每一幕都要拆

- `gap_seconds < 20秒`：无论比例多高都豁免。
- 幕时长 < 30秒：过渡/衔接性短幕，一句话画面描述就够，拆分反而是过度工程化。
- `gap_ratio` 没达到对应门槛：保持一段流畅的画面描述——这仍然是首选写法（见一"写得像分镜提示，不是剧情梗概"），分镜清单只在触发自检时才是必须项，不是所有幕的默认格式。

### 7.6 【音效】在分镜清单里的第二重角色

【音效】在分镜清单场景下可以同时承担剪辑同步点的作用：当某条音效标注了具体时间点（比如"01:12处更鼓声完全消失"），它同时是这个时间点的切换/转场信号，提示剪辑应在这一帧完成镜头切换或声画错位剪辑的衔接——这不是新增字段，只是明确【音效】在这种场景下的第二重用法。
