# 解说台词风格库：叙述人设与措辞变体

`AGENTS.md` Step 2（设计论点与结构）在设计开篇钩子之前使用这份文件来确定"叙述人设"。**这份文件只改变解说词"怎么说"，不改变"说什么"**——论点层层反转的深度产出方法、幕结构/时长要求、版权与事实红线，全部人设通用，不随人设变化（详见三）。

## 一、可选人设

| # | 人设 | 一句话定位 |
|---|---|---|
| ① | **严肃反转型（默认）** | 现有腔调的正式命名：加粗判断句、克制的"你"称呼、大量破折号转折 |
| ② | 学术严谨型 | 冷静克制、重证据轻煽情，读起来像一篇讲究的影评 |
| ③ | 犀利吐槽型 | 辛辣吐槽敢损，网感强度可调，但笑点不越过悲剧的红线 |
| ④ | 温情人文型 | 贴近角色、情感真挚，收尾更像一封信 |
| ⑤ | 悬疑节奏型 | 短句快节奏，每幕结尾都埋一个钩子 |

① 是目前唯一已经落地、被 `examples/` 里的产出验证过的人设——所有其他人设都是在它之外新增的选项，不是替换。

## 二、逐人设详细规则

每个人设都对 `script_format_guide.md` 里的四类开篇钩子、三种转折句模板、结尾收尾给出具体的句式变体——变的是措辞和修辞尺度，不是要不要有钩子/转折句/收尾。每个人设末尾的"镜头节奏"提到的分镜手法（定格延时、声画错位剪辑等）定义见 `script_format_guide.md`（七）。

### ① 严肃反转型（默认）

**声音定位**：戏剧张力来自结构本身，不靠形容词堆砌；用加粗判断句制造"金句感"，克制地使用第二人称，只在揭示时刻用一次。

- **二选一悖论式**：不加修饰的直给句式——"如果一个人穷尽一生都在做『正确的事』，最后却依然……，这到底是A，还是B？"张力来自内容本身，不靠语气词加码。
- **反常识翻案式**：先平铺大众最常见的评价，接一句不加铺垫的"但今天我想反过来讲"，制造预期违背。
- **场景切片倒叙式**：定格一个情绪张力最强的画面，配一句加粗、字幕感的台词或提示，几秒后再切回"大家好，今天聊……"的常规开场。
- **数据/事实反差式**：事实本身用不加修饰的陈述句起头，让认知落差自己说话。
- **转折句**：直接沿用三种既有模板——"这就是……最深层的病理：……"／"这个细节戳破的，不是……，而是……"／"……不是巧合能解释的分量。"
- **收尾**：普世论点用一句有分量的判断句收束；收尾句简短、留有余味；"你"称呼全篇只在揭示核心论点那一刻用一次，其余时候保持第三人称的距离感。
- **措辞/句长**：长铺垫句收束成短的加粗判断句；破折号做转折；形容词克制，情绪爆发点除外。
- **镜头节奏**：单镜平均5-8秒，张力靠内容而非快切堆积——呼应"戏剧张力来自结构本身，不靠形容词堆砌"，剪辑也不用花哨快切喧宾夺主，作为当前的中速基线。

### ② 学术严谨型

**声音定位**：把解说当成一篇讲究的影评来写，证据感优先于戏剧感，第三人称距离感全程保持。

- **二选一悖论式**：改写成评论界既有的解读分歧，而不是直接向观众叫板——"评论界对……历来有两种读法：一种认为……，另一种认为……。哪一种更站得住？"
- **反常识翻案式**：用带出处感的措辞铺陈共识——"学界/普遍评论认为……"，再冷静地接"但这个解读经不起细看"，不用对抗性语气。
- **场景切片倒叙式**：定格画面之后立刻补一句背景注脚（导演、年代、创作背景），不刻意靠留白制造悬念——这个人设不靠"藏信息"取胜，靠"给对信息"取胜。
- **数据/事实反差式**：这个人设最擅长的钩子类型，用"据现存资料记载……"这类带出处感的措辞开场。
- **转折句**：把"金句感"换成分析性框架——"这一情节的功能，与其说是……，不如说是……"／"值得注意的是，……"／"这印证了……这一判断。"
- **收尾**：用"由此可见……"式的分析性结论收束普世论点；不用感叹号；"你"称呼几乎不出现，收尾更接近一段克制的评论结语。
- **措辞/句长**：句长分布均匀，不追求忽长忽短的节奏感；加粗只留给核心论点句，不是每一幕都加粗；不用网络流行语和口语化语气词。
- **镜头节奏**：单镜平均8-12秒，允许更长的静态镜头配合资料闪切/字幕注脚——呼应"证据感优先于戏剧感"，剪辑也该像论文引注一样从容，不追求剪辑感。

### ③ 犀利吐槽型（含网感强度调节）

**声音定位**：辛辣、敢损，靠夸张和自问自答制造反差笑感，但笑点必须服从一条硬规则（见下）。

- **二选一悖论式**：写成自问自答式选择题，narrator 自己揭晓答案并吐槽前面的选项都是陷阱——"A、他活该；B、这套让他『正确』的规矩本来就是场骗局；C、都不是，是我们对『好人』的定义出了问题——选C，因为前两个选项都是陷阱。"
- **反常识翻案式**：先夸张放大大众评价制造喜剧落差——"网上夸XX夸到都要封神了"，再用一句短平快戳破。
- **场景切片倒叙式**：定格画面配一句讽刺感的字幕式吐槽，而不是严肃提示——比如"此刻他绝对没想到，自己正在上演本片最大的讽刺现场"。
- **数据/事实反差式**：陈述事实后接一句吐槽式的括号补刀。
- **转折句**："这就是……最好笑也最难笑的地方：……"／"这个细节撕掉的，不是……的脸，是……"／"……不是巧合，是命运在讽刺。"
- **硬规则（必须遵守）**：任何笑点必须出现在真正的情感高潮**之前**，绝不能和情感爆发点叠加在同一场——这条规则和动画短片方法论里"喜剧和悲剧不要出现在同一场戏里叠加"是同一个原则（见三）。
- **网感强度可调**：全片最多使用 1–2 处当下网络流行语，明确设上限，避免半年后读起来显得过时。
- **收尾**：普世论点用一句俏皮话收束；收尾句不煽情，可以带一点自嘲或调侃。
- **措辞/句长**：短句为主；大量自问自答式的修辞问句。
- **镜头节奏**：单镜平均4-6秒，中快节奏；每处包袱落地后必须接一个1-2秒的沉默反应镜作"包袱停顿"，再切下一镜——没有停顿，包袱会被下一镜盖过去。

### ④ 温情人文型

**声音定位**：贴近角色的情感真实，即使在指控体制/时代，也保留对具体的人的体恤，收尾像写一封信。

- **二选一悖论式**：柔化成邀请式提问，而不是逼观众先站队——"如果一个人拼尽全力想做对每一件事，到最后却还是输了，我们该恨他，还是该抱抱他？"
- **反常识翻案式**：用邀请而不是对抗的语气引出反转——"但如果你愿意再靠近一点看，会发现……"
- **场景切片倒叙式**：用感官/情绪细节（一次呼吸、一个小动作）描述定格画面，而不是冷峻的字幕提示。
- **数据/事实反差式**：陈述事实之后立刻落回具体的人——"这串数字背后，是……个具体的人。"
- **转折句**："这就是……最让人心疼的地方：……"／"这个细节让人鼻酸的，不是……，而是……"／"……这份重量，值得被好好记住。"
- **收尾**：普世论点框定为对当下处境相似的人的一份体恤和邀请；"你"称呼全程可用，不必等到揭示时刻才用；收尾句更温暖，可以直接说"如果你也曾……"。
- **措辞/句长**：多用具体的感官名词而非抽象概念；反讽和黑色幽默克制使用。
- **镜头节奏**：单镜平均6-10秒，多用沉默反应镜和环境音独白段，避免快切打断情绪——镜头节奏和措辞一样，要给情绪留出呼吸的时间。

### ⑤ 悬疑节奏型

**声音定位**：短句快节奏，靠留白和悬置制造推进感，每一幕结尾都是一个没解开的钩子。

- **二选一悖论式**：压缩成短句片段——"两个选择。一个体面。一个要命。他选了哪个？"
- **反常识翻案式**：一句共识短句，接一个硬切——"所有人都这么想。直到——"，反转内容留到下一拍再揭晓。
- **场景切片倒叙式**：这个人设的默认/首选钩子类型——用现在时态描述一个动作正在进行到一半时被切断，不给出结果，逼观众带着悬念往下看。
- **数据/事实反差式**：包装成倒计时感——"还有37天。没人知道这意味着什么——除了他。"
- **转折句**：判断句之后**必须**附加一句前瞻悬念小句——这是唯一允许在转折句里预告下文的人设——"这就是……最深的陷阱：……而下一步，会让这一切彻底失控。"
- **收尾**：普世论点收得快，补一个最后的反转事实作为收尾重锤；收尾句简短，不做长篇抒情。
- **措辞/句长**：全篇以短句/短语为主，多用现在时态；加粗只留给每幕结尾的悬念句，不是每个判断都加粗。
- **镜头节奏**：单镜平均2-4秒，多用声画错位剪辑和平行蒙太奇制造紧迫感，慎用定格延时（放慢等于泄气）——镜头语言要和句子一样短促。

## 三、不随人设改变的部分

无论选哪个人设，以下内容保持不变：

- **论点层层反转的深度产出方法**（`script_format_guide.md` 六）：先给观众直觉认可的解读，再推翻它，再给出更深一层的解读——这是"深度"的来源，人设只改变每一层怎么说，不改变要不要有这个层次。
- **固定幕结构标记**、5–7 幕、8–16 分钟总时长。
- **跨作品对照的存在**：措辞可以随人设变化，但必须出现、且必须找到一个具体的差异点——是否出现、是否够锐利不受人设影响。
- **`AGENTS.md` 里的全部版权/事实红线**：不大段引用台词/原著，不确定的历史/传记细节要么加"据记载……"这类模糊限定语要么直接不写，绝不为了戏剧效果编造具体细节。**③犀利吐槽型和⑤悬疑节奏型是最容易为了效果而夸大或加戏的两个人设，写作时要格外注意不能把"戏剧化的讲法"滑向"编造具体信息"。**
- **喜剧/悲剧不叠加的红线**：这条规则本来是 `animation_fable_guide.md` 五给动画短片定的，这里明确把它扩展成跨人设的通用规则——不止约束③犀利吐槽型，任何人设在处理真正的情感高潮时都不能同时抖机灵。

## 四、和动画短片的关系（范围声明）

**这份风格库只作用于解说词，不覆盖 Step 4/5 的动画短片剧本。**

- `animation_fable_guide.md` 已经有自己独立的语气校准系统（五、戏谑/黑色幽默怎么用得不轻浮），它的差异化维度是"每次换一个新的载体意象"，不是"可切换的叙述人声"。
- 动画短片是场景/对白体剧本，不是第一人称旁白独白，"钩子/转折句/收尾措辞"这套规则在结构上套不到它身上，强行套用会破坏 `output_template.md` 里"两份成稿各自独立，只靠主题呼应和手法对照表关联"的现有结构。
- **可选的软联动**：如果选中的解说人设自然地暗示动画短片的黑色幽默强度该调高或调低（比如解说词选了③犀利吐槽型），可以顺势让动画短片的语气拿捏往同一个方向靠一点，但这不是 Step 4/5 的强制要求，不自然就不要硬凑。

## 五、人设选择逻辑

**优先从用户请求原文里推断语气，只有语气不明确时才主动问。** 常见的语气信号词：

| 请求里出现的措辞（同义/近义都算） | 对应人设 |
|---|---|
| 吐槽向 / 犀利 / 敢损 / 玩梗 / 网感强 | ③ 犀利吐槽型 |
| 温情 / 治愈 / 走心 / 感人 | ④ 温情人文型 |
| 悬疑 / 节奏快 / 留悬念 / 紧张感 | ⑤ 悬疑节奏型 |
| 学术 / 严谨 / 别整虚的 / 讲究考据 | ② 学术严谨型 |
| 没有以上任何信号 | 不问，直接用 ① 严肃反转型（默认） |

命中多个信号词、或信号本身相互矛盾时，才使用下面的提问模板主动问一次；不要在信号已经明确时还追问，那是不必要的摩擦。

## 六、推荐话术模板

```
这次的深度解说词想用哪种叙述人设？
1. 严肃反转型（默认，目前的标准调性——论点层层反转，判断句克制有分量）
2. 学术严谨型（克制冷静，重证据轻煽情，像一篇讲究的影评）
3. 犀利吐槽型（辛辣吐槽，敢损，但笑点不越过悲剧的红线）
4. 温情人文型（贴近角色，情感真挚，收尾更像一封信）
5. 悬疑节奏型（短句快节奏，留悬念，每幕结尾都埋一个钩子）
不回复的话默认用 1. 严肃反转型（跟现在的输出保持一致）。
```
