# Working in this repo

The complete workflow, copyright rules, and output requirements live in
[`AGENTS.md`](AGENTS.md) at the repo root. Read it in full and follow it whenever a request
matches what it describes (a movie title or film-commentary link → deep commentary script +
original animated short).

If this project is installed as a Claude Code skill (`~/.claude/skills/cine-remix/`), the
skill's own `SKILL.md` handles triggering automatically and this file usually isn't needed —
it exists for the case where someone opens this repo directly in Claude Code without installing
it as a skill first.
